## 📦 Tecnologias Utilizadas

### 🖥️ Frontend
- **React.js**
- **React Hook form (validaçoes em forms)  react-hook-form.com/get-started/#SchemaValidation**
- **React Select (https://react-select.com/home)**
- **React Toastify (pop-up de notificação) (https://www.npmjs.com/package/react-toastify)**
- **Vite**
- **Axios (comunicar Front com o backend)**
- **React Router DOM**
- **Styled-components (ou CSS Modules)**
- **ESLint + Prettier**
- **Sripe docs(Pagamentos) (https://docs.stripe.com/payments/quickstart?client=react)**
- **yup (validação de valores)**
- **Material Ui**
- Phosphoricons para icones (https://phosphoricons.com/)

### 🔙 Backend
- **Node.js**
- **Express.js**
- **Sequelize**
- **SQLite / PostgreSQL**
- **MongoDb Compass (Para os pedidos)**
- **JWT (Autenticação)**
- **Multer (upload de imagens)**
- **yup (validação de valores)**
- ** Stripe para pagamentos **

## 📑 Funcionalidades

<h3>Para Clientes</h3>

- 🔐 Autenticação e registro de conta
- 🍔 Navegação pelo cardápio de produtos
- 🛒 Adição de itens ao carrinho
- 🔍 Filtro e busca de produtos
- 💰 Checkout e pagamento
- 📱 Acompanhamento de pedidos
  
<h3>Para Administradores</h3>

- ✏️ Gerenciamento de produtos (CRUD)
- 📋 Gerenciamento de pedidos

## Pré-requisitos

Node.js (v14.x ou superior)
npm para o backend e Yarn para o frontend
MongoDB (local ou instância na nuvem)
Docker Container

# Frontend

#### Clonar o repositório
git clone https://github.com/seu-usuario/devburger.git

#### Entrar no diretório do frontend
cd devburger/frontend

#### Instalar dependências
yarn install

#### Iniciar o servidor de desenvolvimento
yarn dev

#### Acesse o navegador
http://localhost:5173

----
# Backend

#### Clonar o repositório
git clone https://github.com/seu-usuario/devburger.git

#### Entrar no diretório do frontend
cd devburger/frontend

#### Instalar dependências
npm install

#### Crie o arquivo .env com as variáveis necessárias
.env
#### Rode as migrations
npx sequelize db:migrate

#### Iniciar o servidor de desenvolvimento
npm run dev
